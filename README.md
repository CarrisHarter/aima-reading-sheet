# AIMA 4th Global Edition — reading sheet

Interactive day-by-day reading tracker: 56 days, PDF pp. 19–1118, deadline 2027-01-05.

- Single self-contained `index.html` (no build, no dependencies).
- Click a checkbox to tick a day; progress bar, % and page counts update live.
- Ticks persist in the browser via `localStorage`.
- Regenerated from `~/.pi/agent/reading-plan.json` via the pi `/reading` extension.
